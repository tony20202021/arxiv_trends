# arXiv Keyword Trends Pipeline

Цель: строить **тренды по ключевым словам из Abstract** научных статей arXiv по разным доменам.

## Что делает пайплайн
- Читает список доменов из `config/domains.json`
- Для каждого домена:
  - получает список статей из arXiv (через arXiv API Atom)
  - скачивает HTML страницы `/abs/<id>` (HTML-режим)
  - извлекает **только Abstract**
  - извлекает ключевые слова (токены/слова; настройки — в `config/constants.py`)
  - агрегирует по неделям за последний год
  - сохраняет сырые агрегаты в MongoDB: `(domain, week_start, keyword, count)`
  - строит 2 графика:
    1) **Top-10 самых популярных** на последней неделе (показываются только эти 10 линий, история 1 год)
    2) **Top-10 самых быстро-растущих** за последние 10 недель (показываются только эти 10 линий, история 1 год)

Результат: по каждому домену — **пара графиков** в `outputs/plots/<domain>/`.

## Быстрый старт
1) Установить зависимости:
```bash
pip install -r requirements.txt
```

2) Поднять MongoDB и настроить `.env`:
```bash
cp .env.example .env
```

3) Один прогон (обновить данные + построить графики):
```bash
python scripts/run_pipeline.py --mode full
```
