# Диагностика

## Покрытие БД по доменам

Показывает список доменов с диапазоном недель и суммарным количеством упоминаний ключевых слов.

```bash
cd /path/to/arxiv_trends && python scripts/check_db.py
```

Пример вывода:

```
Домен          С            По            Недель   Упоминаний
-------------------------------------------------------
cs_lg          2026-01-06   2026-03-30        13      541,204
cs_ro          2026-01-06   2026-03-30        13      229,698
stat_ml        2026-01-06   2026-03-30        13      183,992
```

Опции:

```bash
python scripts/check_db.py --uri mongodb://host:port --db db_name
```

По умолчанию берёт `MONGO_URI` и `MONGO_DB` из `.env`.
