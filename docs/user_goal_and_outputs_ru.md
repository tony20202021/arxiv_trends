# Цель и результат пайплайна (взгляд пользователя)

## Зачем нужен этот пайплайн
Цель пайплайна — смотреть тренды по ключевым словам в научных статьях по разным доменам.

- статьи берутся с arXiv
- режим получения: HTML (`/abs/<id>`)
- ключевые слова извлекаются **только из abstract**
- список доменов берётся из JSON-файла

---

## Что пользователь получает на выходе
По каждому домену — 2 графика (по неделям, длиной в год от текущей даты назад):

### 1) Top-10 самых популярных слов сейчас
- выбираются слова, которые входят в top-10 на **последней неделе**
- на графике показываются линии **только этих 10 слов** за год

### 2) Top-10 самых быстро-растущих за последние 10 недель
- выбираются слова с максимальной скоростью роста за последние 10 недель
- на графике показываются линии **только этих 10 слов** за год
